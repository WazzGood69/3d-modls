# WOLBET 3D MODELS

## human_ps1_v1
First test character for Wolbet.

- Realistic human proportions
- Intentionally low-poly / PS1-era geometry
- Faceted, un-smoothed surfaces
- Separate materials for skin, clothing, boots, hair, and eyes
- Neutral T-ish pose suitable for testing in the game
- OBJ + MTL, so it can be loaded without a GLTF pipeline

This is **V1 for visual testing**. If the shape is not right, the next version can change the body proportions, face, clothing, polygon density, or PS1 look.
